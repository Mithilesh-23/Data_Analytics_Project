# HR Employee Attrition Analysis

## 📌 Overview

This project analyzes employee attrition to identify factors associated with employees leaving an organization.

The analysis uses **Python, SQL, SQLite, and Power BI** to perform data cleaning, exploratory analysis, SQL analysis, and interactive dashboard development.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- SQL
- SQLite
- Power BI
- Jupyter Notebook

## 📊 Dataset

- **1,470 employees**
- **35 columns**
- No missing values
- No duplicate records

## 🔍 Key Analysis

- Department-wise attrition
- Overtime vs attrition
- Job role attrition
- Age-group attrition
- Monthly income comparison
- Tenure analysis
- Job satisfaction
- Work-life balance

## 📈 Key Insights

- **Total Employees:** 1,470
- **Employees Left:** 237
- **Attrition Rate:** 16.12%
- **Highest Department Attrition:** Sales – 20.63%
- **Highest Job Role Attrition:** Sales Representative – 39.76%
- **Overtime Attrition:** 30.53%
- **Non-Overtime Attrition:** 10.44%
- **Highest Age Group Attrition:** 18–25 – 35.77%
- **0–2 Years Tenure Attrition:** 29.82%

Employees who left also had a lower average monthly income (**4,787.09**) compared with employees who stayed (**6,832.74**).

> These findings show associations in the dataset and do not establish causation.
